# pmquotes-data

Public, static mirror of Bowerbird's Australian equity fund-manager podcast insights.
Every file is a plain JSON or CSV document served over HTTPS from GitHub, so it works
from anywhere that allows github.io and raw.githubusercontent.com. No API key, no auth,
no login.

- Rows: **47,382**
- Date range: **2016-07-01** to **2026-08-07**
- Distinct ASX codes: **195**, managers: **367**, shows: **269**
- Generated: **2026-08-08T06:02:02.000780+00:00**

Regenerated by the Bowerbird nightly. The published branch is a single orphan commit that
is force-pushed each run, so the repository does not grow over time.

## Base URLs

Two independent paths. Use whichever your network allows.

- GitHub Pages: `https://duriandaniel.github.io/pmquotes-data/`
- Raw: `https://raw.githubusercontent.com/duriandaniel/pmquotes-data/main/`

## Fetch it

### The whole feed

```bash
curl -sSL -o insights.json https://duriandaniel.github.io/pmquotes-data/insights.json
curl -sSL -o insights.json https://raw.githubusercontent.com/duriandaniel/pmquotes-data/main/insights.json
```

Pre-gzipped, roughly a fifth of the bytes:

```bash
curl -sSL https://duriandaniel.github.io/pmquotes-data/insights.json.gz | gunzip > insights.json
curl -sSL https://duriandaniel.github.io/pmquotes-data/insights.csv.gz | gunzip > insights.csv
```

### Just the last 30 days

```bash
curl -sSL https://duriandaniel.github.io/pmquotes-data/latest-30d.json | head -c 2000
```

### One ticker

```bash
curl -sSL https://duriandaniel.github.io/pmquotes-data/by-ticker/BHP.json -o BHP.json
curl -sSL https://raw.githubusercontent.com/duriandaniel/pmquotes-data/main/by-ticker/BHP.json -o BHP.json
```

### One manager

```bash
curl -sSL https://duriandaniel.github.io/pmquotes-data/by-manager/salt.json -o salt.json
```

### Indexes and manifest

```bash
curl -sSL https://duriandaniel.github.io/pmquotes-data/tickers.json
curl -sSL https://duriandaniel.github.io/pmquotes-data/managers.json
curl -sSL https://duriandaniel.github.io/pmquotes-data/manifest.json
```

### Context files


## pandas

```python
import pandas as pd

BASE = "https://duriandaniel.github.io/pmquotes-data/"

# Whole feed. pandas reads gzip over HTTP transparently.
df = pd.read_csv(BASE + "insights.csv.gz")

# Or the JSON form, which keeps nulls typed properly.
df = pd.read_json(BASE + "insights.json")

# Recent only, much faster to pull.
recent = pd.read_json(BASE + "latest-30d.json")

# One ticker.
bhp = pd.read_json(BASE + "by-ticker/BHP.json")

# One manager.
mgr = pd.read_json(BASE + "by-manager/salt.json")

# Indexes.
tickers = pd.read_json(BASE + "tickers.json")
managers = pd.read_json(BASE + "managers.json")

# Typical slice: bullish calls on one name in the last year.
df["published_at"] = pd.to_datetime(df["published_at"], utc=True, errors="coerce")
view = df[(df.asx_code == "BHP") & (df.stance == "bullish")].sort_values("published_at", ascending=False)
```

2. Paste `https://duriandaniel.github.io/pmquotes-data/insights.csv`
3. Load. For a single name use the smaller shard instead, for example

## Fields

| Field | Meaning |
| --- | --- |
| `id` | Stable sha256 content hash of the insight. Primary key, safe to dedupe on. |
| `published_at` | ISO 8601 UTC publication timestamp of the SOURCE episode. Null when the source date could not be determined. Never an ingest timestamp. |
| `manager_name` | Display name of the fund manager or firm the speaker represents. Null when the speaker's firm is unknown. Media platforms are never managers. |
| `manager_slug` | Canonical manager identifier. Join key for by-manager shards and managers.json. |
| `manager_alias` | Alternate name the manager appeared under in the source, if any. |
| `speaker_name` | Name of the person who made the statement. |
| `speaker_type` | Role of the speaker: portfolio_manager, analyst, commentator, host, guest, other. |
| `show_name` | Podcast show display name. |
| `show_slug` | Podcast show identifier. |
| `show_homepage` | Homepage URL of the podcast show. |
| `kind` | Insight category, e.g. stock_view, macro_view, sector_view, portfolio_action. |
| `asx_code` | Resolved ASX ticker, uppercase. Null for macro or unresolved mentions. |
| `ticker_raw` | Ticker exactly as spoken or written in the source. |
| `company_name` | Resolved company name for asx_code. |
| `company_name_raw` | Company name as it appeared in the source. |
| `sector` | GICS sector of the company, when resolved. |
| `region` | Region the view applies to, e.g. AU, US, GLOBAL. |
| `stance` | Directional stance: bullish, bearish, neutral, discuss. |
| `conviction` | Conviction level when stated: high, medium, low. Often null. |
| `headline` | One-line summary of the view. Full text, not truncated. |
| `reasoning` | Supporting rationale. TRUNCATED to ~100 characters in this slim feed (see text_truncated). |
| `quote` | Verbatim quote from the speaker. TRUNCATED to ~100 characters in this slim feed (see text_truncated). |
| `text_truncated` | True when reasoning/quote were truncated for size. Always true in this feed. |
| `manager_holds_asx` | True if the manager had a disclosed holding in asx_code at the nearest disclosure date. |
| `manager_holding_weight_pct` | Portfolio weight percent of that disclosed holding. |
| `manager_holding_as_of` | As-of date of the disclosure used for manager_holds_asx. |
| `is_institutional` | True when the speaker's firm is an institutional investor rather than a retail commentator. |
| `episode_title` | Title of the source episode. |
| `episode_url` | Direct URL to the source audio. |

### Dates

`published_at` is always the source episode's own publication date. When the source date
could not be determined it is `null`, never an ingest timestamp. Treat `null` as unknown,
not as today.

### Truncated text

`reasoning` and `quote` are truncated to about 100 characters so the feed stays practical
to move over a corporate link. `headline` is complete. Rows carry `text_truncated: true`.

## Verifying an download

`manifest.json` carries a SHA-256 for every file:

```bash
curl -sSL https://duriandaniel.github.io/pmquotes-data/manifest.json | python3 -c \
  "import json,sys; m=json.load(sys.stdin); print(m['row_count']); [print(f['sha256'][:12], f['bytes'], f['path']) for f in m['files'][:10]]"
curl -sSL https://duriandaniel.github.io/pmquotes-data/insights.json | sha256sum
```
